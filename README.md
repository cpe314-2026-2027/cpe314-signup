# CPE 314 — Signup

If you're a student in CPE 314 (Software Design & Software Design Laboratory), this is how you
get your course repository set up.

## What to do

1. Make sure you have a GitHub account. If not: [github.com/signup](https://github.com/signup).
2. Click **Issues** (above) → **New issue** → choose the **CPE 314 Signup** template.
3. Fill in your full name (matching the official class list) and your section, then submit.
4. Wait for a **GitHub notification/email** inviting you to your new private course
   repository — usually within a day or two. Accept it from
   [github.com/notifications](https://github.com/notifications).

That's it — this issue is the only thing you need to submit here. Your actual coursework
happens in the private repository you'll be invited to, not in this repo.

## Why this is public

This repo is public so any GitHub account can open an issue here without needing to be invited
first. Only your name, GitHub username (recorded automatically as the issue author), and
section are collected — nothing more sensitive is asked for here.
